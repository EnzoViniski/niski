# Pacote de skills do Niski

O aplicativo inclui quatro skills reutilizáveis. Em Configurações → Skills, use **Instalar pacote Medza** para copiá-las para as contas de Claude/Codex. O app preserva versões já existentes, inclusive as desativadas. Instalar uma skill não obriga a CLI a usá-la em toda tarefa.

| Skill | Uso | Origem |
|---|---|---|
| frontend-design | Direção visual de interfaces | Anthropic, example-skills |
| webapp-testing | Testes web com Playwright | Anthropic, example-skills |
| copywriting | Texto de páginas e campanhas | Corey Haines, marketing-skills |
| seo-audit | Auditoria de SEO | Corey Haines, marketing-skills |

As pastas em `basicas/` incluem instruções, referências, exemplos e licenças. Instalar faz uma cópia; não executa os scripts das skills. Algumas tarefas dessas skills precisam de ferramentas adicionais, como Playwright, instaladas no projeto em que forem usadas.

O pacote não contém memória pessoal, contas ou histórico de conversas.
